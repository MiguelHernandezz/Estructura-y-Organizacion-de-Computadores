## 📘 What the subject covers

> **Estructura y Organización de Computadores (780010)** · 6 ECTS · 1st year · 2nd semester · contents from the 2024-25 teaching guide · [official subject page](https://www.uah.es/es/estudios/estudios-oficiales/grados/asignatura/Estructura-y-Organizacion-de-Computadores-780010/)

| Unit | Hours | Topics |
|---|---|---|
| The datapath | 6 h | Performance · Fast integer addition · Multiplication and division |
| Instruction set architecture | 6 h | Instruction types and addressing modes · Encoding and formats · RISC vs CISC |
| The control unit | 6 h | Micro-operations and timing diagrams · Microprogramming |
| Memory | 5 h | Memory hierarchy · Cache memory |
| Input/output | 5 h | Synchronisation · Buses · Mass storage |
